# eFootball Squad Toolkit — feature reference

eFootball Squad Toolkit uses a concise workspace for squad profiles, tactic notes, and match records. The feature map follows the same order as the project navigation.

| Section | Description |
|---|---|
| Squad profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Tactic notes | A dedicated section for tactic notes and the configuration details associated with that area. |
| Match records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
